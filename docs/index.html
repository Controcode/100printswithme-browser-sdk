@100printswithme/browser-sdk

Render templates. Right in the browser.

Generate PNG, JPEG, PDF, and vector PDF files from 100PrintsWithMe templates using a browser-safe publishable key. No backend renderer required.

Try Playground → Create Template

Installation

Install the Browser SDK using your package manager.

npm install @100printswithme/browser-sdk
pnpm add @100printswithme/browser-sdk

Quick Start

Create the client once, then reuse it throughout your application.

TypeScript 
import { HundredPrints } from "@100printswithme/browser-sdk";

const prints = new HundredPrints({
  publishableKey: "pk_live_xxx"
});

const image = await prints.png({
  templateId: "tpl_123",

  data: {
    Name: "Rishabh Dev",
    Role: "Chief Scientist"
  },

  side: "front",
  quality: "high"
});

document.querySelector("#preview").src = image.url;

Use a browser-safe publishable key. Never expose secret API keys in client-side JavaScript.

Core API

These are the methods most integrations need.

prints.png()

Render one template side as PNG. Requires side: "front" or "back".

prints.jpeg()

Render one template side as JPEG.

prints.pdf()

Generate a raster PDF. Use includeBack: true for two-page templates.

prints.vectorPdf()

Generate a PDF with selectable text and supported vector artwork.

prints.renderTo()

Render PNG or JPEG directly into an <img>.

prints.download()

Render and download a file in one operation.

Image

PNG 
const image = await prints.png({
  templateId: "tpl_123",
  data: { Name: "Rishabh Dev" },
  side: "front",
  quality: "high"
});

image.download("certificate.png");

// When the URL is no longer needed:
image.revoke();

PDF

PDF 
const pdf = await prints.pdf({
  templateId: "tpl_123",
  data: { Name: "Rishabh Dev" },
  includeBack: true,
  quality: "high"
});

pdf.download("document.pdf");

Render into an image

renderTo() 
<img id="preview" alt="Preview">

<script>
await prints.renderTo("#preview", {
  templateId: "tpl_123",
  data: { Name: "Rishabh Dev" },

  output: {
    format: "png",
    side: "front",
    quality: "high"
  }
});
</script>

HTML 
<script
  src="https://cdn.jsdelivr.net/npm/@100printswithme/browser-sdk@2.0.0/dist/100prints-sdk.umd.js">
</script>

<script>
const prints = new HundredPrints({
  publishableKey: "pk_live_xxx"
});
</script>

The UMD build exposes HundredPrints on window.

Good to know

Object URLs

Render results include a local browser url. It is useful for previews and downloads but is not a permanent public URL.

Fonts

Template fonts are resolved automatically using custom fonts, the 100PrintsWithMe font library, Google Fonts, and safe fallbacks.

Browser only

Rendering uses browser APIs including Canvas, Fetch, Blob, and object URLs.
